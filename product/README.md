# SoundMatch
From portfolio root:
```
python -m scripts.build_soundmatch
python -m pytest tests/test_soundmatch.py -q
python -m portfolio.server
```
Open http://127.0.0.1:8765/soundmatch. Choose genres, energy and tempo, save a recommendation, skip another, reload, and undo feedback in the collection panels. Empty genre preferences use a neutral genre contribution plus the user's energy/tempo settings. Saved tracks blend metadata into subsequent scores; saved/skipped tracks are excluded. Greedy ranking includes at most one track per artist per slate.

480 fictional tracks, 60 fictional artists, six genres. There is no external data source, audio, artwork license dependency or Spotify integration. Metadata is generated by NumPy seed 20261117.

Evaluation: 160 synthetic users each receive 30 generated positive preferences under noisy latent utility. Ten interactions are observed, twenty held out. Profile reconstruction uses only the ten training tracks. Metadata for candidate tracks is known, as appropriate for content-based ranking. Holdout interactions never influence ranking. A popularity comparison uses training counts only. The synthetic utility and ranking use related attributes; results demonstrate internal consistency, not real-world recommendation quality.
